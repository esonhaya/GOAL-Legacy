# Purpose

The Pulse table stores public discussion generated by football events throughout GOAL: Legacy.

Pulse represents the living conversation surrounding football.

Unlike News, which records facts, Pulse records opinions, reactions, jokes, debates, praise, criticism, and trends.

Pulse is the emotional heartbeat of the football world.

---

# Ownership

Primary Module

Pulse Module

Supporting Modules

- News
- Match
- Player
- Club
- Staff
- Relationship
- Legacy

Only the Pulse Module may directly create or modify Pulse records.

---

# Design Principles

- One record per discussion.
- Permanent Pulse ID.
- Event-driven generation.
- Dynamic AI participation.
- Historical preservation.

---

# Lifecycle

Pulse discussions are generated when meaningful events occur.

Examples include:

- Match Results
- Transfers
- Manager Sackings
- Trophy Wins
- Player Mistakes
- Wonder Goals
- Injuries
- Awards
- Financial Crises

Activity naturally declines over time before becoming historical.

---

# Primary Key

Pulse ID

Properties

- Permanent
- Unique
- Never reused
- Never edited
