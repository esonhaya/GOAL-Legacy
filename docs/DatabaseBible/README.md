# Database Bible

## Purpose

The Database Bible defines the persistent data model of GOAL: Legacy.

It specifies every major database entity, its responsibilities, ownership, relationships, and future expansion strategy.

The Database Bible does not define gameplay logic. Instead, it defines **what data exists**, **who owns it**, and **how it connects to other systems**.

---

## Design Principles

- Data-driven architecture
- Modular ownership
- Permanent identifiers
- Historical preservation
- Future-proof expansion
- Minimal data duplication
