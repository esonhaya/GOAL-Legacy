# Technical Bible

## Purpose

The Technical Bible defines the software architecture of GOAL: Legacy.

It explains how the game is organized internally, including project structure, module ownership, save architecture, development workflow, and technical standards.

Unlike the Database Bible, the Technical Bible focuses on **how the software is built**, not on gameplay mechanics.

---

## Design Principles

- Modular architecture
- Loose coupling
- Event-driven systems
- Maintainability
- Scalability
- Long-term development
